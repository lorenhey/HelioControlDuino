# Política de seguridad

## Versiones mantenidas

La versión estable más reciente recibe correcciones de seguridad. Las versiones
anteriores pueden dejar de recibir soporte cuando se publica una nueva versión
estable.

## Informar una vulnerabilidad

No publiques vulnerabilidades en Issues. Usá **Security > Report a
vulnerability** en el repositorio para enviar un reporte privado con:

- versión o commit afectado;
- placa y configuración de hardware;
- descripción del impacto;
- pasos mínimos para reproducir el problema;
- mitigación conocida, si existe.

Los reportes se revisarán antes de divulgar detalles. En sistemas que controlan
cargas mecánicas o eléctricas, desconectá los actuadores y utilizá protecciones
físicas independientes durante cualquier prueba.
